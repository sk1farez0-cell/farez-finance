FAREZ FINANCE — VERSION WEB INITIALE

Contenu :
- index.html : application web responsive en français
- manifest.webmanifest : métadonnées d'installation PWA
- sw.js : cache hors ligne de base
- icons/icon.svg : icône de l'application

PUBLICATION
1. Décompresser l'archive.
2. Envoyer le CONTENU du dossier à la racine d'un dépôt GitHub.
3. Dans Settings > Pages, choisir Deploy from a branch, main, /(root).
4. Attendre l'adresse publique fournie par GitHub Pages.
5. Connecter ensuite farezfinance.com dans Settings > Pages et configurer les DNS selon les indications de GitHub.
6. HTTPS doit être activé avant l'installation PWA.

INSTALLATION SUR IPHONE
Quand le site est publié en HTTPS : ouvrir son adresse dans Safari > bouton Partager > Sur l'écran d'accueil > Ajouter.

LIMITES ET PRUDENCE
Cette version est éducative. Elle ne traite aucun paiement, ne crée aucun compte financier et ne propose aucun service bancaire ou d'investissement.
Aucun partenariat n'est confirmé. Toute évolution vers des services réglementés nécessite des professionnels et autorisations appropriés.
Le domaine farezfinance.com n'est pas réservé par cette archive.
